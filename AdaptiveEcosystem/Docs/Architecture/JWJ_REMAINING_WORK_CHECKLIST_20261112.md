## 지금 플레이에서 확인할 항목

### 풀 표현과 환경 디버그

- [ ] `eco.Grass.Visual 0`과 `1`을 번갈아 적용한다. 먹이와 연동된 풀이 사라졌다 돌아오는 동안 사슴의 시뮬레이션이 진행되는지 본다. 4지역을 이동하며 카메라 회전과 거리 변화에 따른 표시도 확인한다.
- [ ] Inspector에서 `Alt+G`로 환경 패널을 열고 지역 선택, 기후 변경, 자동 복귀, 진단 저장을 조작한다. 선택 지역만 영향을 받고 자동 복귀 후 최신 자동 기후가 적용되는지, `Saved/FoodGrass`에 진단 결과가 생기는지 확인한다.

### 사슴 지역 순차 이주

새 **Standalone Game**에서 아래 명령을 한 줄씩 실행한다. 가뭄 명령은 시험용으로 먹이와 재생을 조작하므로 확인 후 세션을 종료하고 다시 시작한다.

```text
eco.HerdMigration 1
eco.HerdMigration.Regional 1
eco.HerdMigration.Debug 2
eco.HerdMigration.Test.Drought JWJ_WildlifeTest
```

- [ ] `M`으로 지도 표시, `[`와 `]`로 계획을 선택한다. 등록 순서와 출발 간격을 확인한다. 12마리 시작·추가 사망 없음·유효 목적지 조건에서는 최대 9마리 승인, 예상 잔류 3마리에서 멈춘다. 경로·목적지 제약이 있으면 더 일찍 멈출 수 있다.
- [ ] 같은 `StableAgentId`가 실제 경로를 이동해 `RegionId`가 바뀌고 `Settled`에 도달하는지 확인한다. 출발·도착 지역의 인구와 이주 장부를 대조한다.
- [ ] 단독 개체, 목적지 경쟁·경로 실패, 이동 중 사망·재시도를 확인한다. 활성 이주 중 저장 후 별도 프로세스에서 지역 등록 순서와 승인 이력을 복원하고, Dedicated 서버·클라이언트 2대와 늦은 접속에서 이주 표현을 확인한다. 기존 v5 복원 검증은 Regional OFF 조건이었다.

### 사슴 이동 계측과 사격 표시

- [ ] 최신 로컬 빌드에서 `eco.MoveTrace.Agent <사슴 ID>`로 평상시 먹이 이동과 늑대 접근 시 도주를 각각 기록한다. 최대 225스텝 또는 `eco.MoveTrace.Agent 0` 입력 후 `Saved/Profiling/EcoMovement`에 CSV가 생성되는지 확인한다. `behavior`·`seq`, 최종 보행, 실제 변위를 비교한다. Insights에서는 같은 구간의 `EcoMotionBegin`·`EcoMotionEnd`와 Native Step 타이머를 확인한다.
- [ ] 사냥 플레이에서 생존 상태로 총기를 장착하면 중앙 조준점이 보이고, 해제하거나 사망하면 사라지는지 확인한다. 발사 시 로컬 사수에게 짧은 붉은 궤적이 보이는지, 다른 클라이언트에서는 해당 디버그 선이 표시되지 않는지 확인한다.
